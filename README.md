# Leonildo Alexandre Morgado
## Academic & Instructional Design Portfolio

An advanced professional portfolio showcasing evidence-based curriculum design, Task-Based Language Teaching (TBLT) frameworks, interactive diagnostic tools, and higher education course artifacts.

🚀 **Overview**

This portfolio bridges rigorous Second Language Acquisition (SLA) research, outcome-based education (OBE), and modern web-native engineering. Designed for post-secondary academic appointments, EAP/ESP pathway programs, and educational technology collaborations, it features 32 fully-articulated course specifications and interactive diagnostic tools.

🛠️ **Core Capabilities**

* **Task-Based Language Teaching (TBLT):** Designing instructional sequences moving from pre-task schema activation to collaborative task execution and focused form-focus feedback.
* **Web-Native Learning Engineering:** Building high-performance, responsive, zero-overhead educational modules utilizing HTML5, Tailwind CSS, and interactive JavaScript engines.
* **Cognitive Scaffolding & UDL:** Structuring course architectures, multi-tiered rubrics, and diagnostic tools to eliminate cognitive load and support diverse learner profiles.
* **Response-Reactive Diagnostics:** Developing algorithmic H5P and interactive modules that evaluate learner proficiency in real-time and balance peer collaborative cohorts.
