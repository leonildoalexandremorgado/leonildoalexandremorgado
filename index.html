1. Response-Reactive Branching

Uses multi-branch decision trees to dynamically adapt task difficulty based on real-time learner inputs, reducing test anxiety while capturing granular proficiency markers.

2. Hierarchical Scoring

Evaluates task performance across discrete linguistic and communicative metrics rather than simple pass/fail outcomes, generating multi-dimensional skill profiles.

3. Cohort Balancing Algorithm

Automatically pairs and groups learners into heterogenous or homogenous cohorts optimized for peer scaffolding during subsequent communicative tasks.
